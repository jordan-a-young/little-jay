# Canonical brand assets

- Read `README.md`, `docs/BRANDING.md`, and `docs/PEBBLE-STATES.md` for the affected assets. Keep this package framework-independent; React presentations belong in UI.
- Preserve approved artwork, SVG viewBoxes, image proportions, source provenance, and font notices. Do not redraw artwork in CSS/JSX or replace canonical assets incidentally.
- `README.md#provenance-and-rights` records the creator's ChatGPT-assisted provenance statement and artwork's exclusion from the code/documentation MIT grant. Preserve that distinction and third-party notices; do not grant additional artwork or trademark permissions without explicit authorization.
- Asset exports and the `files` allowlist are deliberate. Do not ship source ZIPs, reference rasters, preview sheets, or font binaries. Keep state manifests aligned with approved PNGs.
- Browser copies are generated by `apps/playground/branding.ts`; change canonical assets and the explicit synchronization allowlist as needed, not generated public files.
- This asset package has no build/typecheck/test script. Validate changed asset/export targets through `pnpm build` and the root package-consumer check; check affected browser usage and deployment base paths when relevant.
