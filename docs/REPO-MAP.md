# Task-to-file map

All paths below are relative to the repository root. Start with the matching row and read the applicable `AGENTS.md` files before editing. Tests run through the root configuration; see [root guidance](../AGENTS.md#commands-and-verification) for commands and the [verification matrix](VERIFICATION.md) for check selection and build prerequisites.

This is a navigation aid, not a complete inventory. Check current code before assuming a path or contract is authoritative. Keep this map and affected scoped guidance current in the same change when workspace layout, task ownership, mapped paths, entry points, generators, or test locations change. Add a row for a new task area, update moved paths, and remove obsolete entries. No update is needed for internal edits that leave the map accurate.

## Shared libraries

Integer setting drafts and commits are owned by `@littlejay/ui`: start at `packages/ui/src/numeric-input/` and its colocated tests. The control composes native Input/Field; `packages/ui/README.md#numericinput` defines valid blur/Enter commits, invalid/empty restoration, controlled updates and reset behavior. Root/subpath/build exports and `scripts/test-packages.mjs` cover distribution. Forms examples live at `/#/numeric-input`; verify native keyboard, wheel, validity, focus, reset, themes/narrow/zoom and the reset-free consumer. Saving, domain validation and conflict policy remain application-owned.

Modal Dialog and sheet layouts are owned by `@littlejay/ui`: start at `packages/ui/src/dialog/index.tsx`, `packages/ui/src/styles.css` and `packages/ui/src/dialog/dialog.component.test.tsx`. React Aria owns layered overlay behavior; `packages/ui/README.md#dialog` defines application-owned CSP nonces, dismissal and focus contracts. Inspection catalog examples and `scripts/test-packages.mjs` cover public root/subpath and reset-free consumers. Validate nested Combobox Escape ordering, focus restoration, background isolation/scroll locking, scoped themes and narrow layouts in Chromium; nonce authorization is not literal self-only CSP support.

Native inline and button-styled navigation is owned by `@littlejay/ui`: start at `packages/ui/src/link/`, `packages/ui/src/button-link/` and `packages/ui/src/styles.css`. Root/subpath/build exports, the installed UI README and `scripts/test-packages.mjs` cover distribution. Actions catalog pages/examples live in `apps/playground/src/catalog/link/`, with registry and catalog tests. Verify native anchors/ref/hidden/current-page behavior, Enter and modified/middle navigation, theme/long-label/narrow presentation and a reset-free packed consumer; routing stays application-owned.

Switch on/off controls are owned by `@littlejay/ui`: start at `packages/ui/src/switch/index.tsx`, `packages/ui/src/styles.css`, and the colocated `switch.component.test.tsx`. Root/subpath/build exports and `scripts/test-packages.mjs` cover distribution; usage/examples and their tests live in `apps/playground/src/catalog/forms/`. Check keyboard/focus, native forms, Field associations, both themes, narrow layouts and reset-free consumers.

## Applications

Searchable local selection is owned by `@littlejay/ui`: start at `packages/ui/src/combobox/index.tsx`, `packages/ui/src/styles.css` and colocated `combobox.component.test.tsx`. Field label IDs live in `packages/ui/src/field/`; root/subpath/build exports, `packages/ui/README.md#combobox` and `scripts/test-packages.mjs` cover distribution. Forms catalog examples/test adoption cover synthetic local projects. Check keyboard/IME/pointer, query versus selected-ID forms, cancellation/external-form reset, required/disabled/hidden semantics, theme/modal portals and wide/narrow reset-free rendering.

Example selection is playground-owned: `apps/playground/src/catalog/ExampleTabs.tsx` and colocated `ExampleTabs.component.test.tsx` supply route-controlled manual underline tabs with active-only panels. `DocumentationPage.tsx`, catalog/router component tests and app `styles.css` cover integration. Preserve hash/history, focus and preview-reset semantics; check native keyboard activation, long-label horizontal overflow, both themes and narrow layouts. Shared Tabs' visited-panel caching is intentionally not used here.

Breadcrumb composition is owned by `@littlejay/ui`: start at `packages/ui/src/breadcrumb/index.tsx`, `packages/ui/src/styles.css` and colocated `breadcrumb.component.test.tsx`. Root/subpath/build exports, installed `packages/ui/README.md#breadcrumb` and `scripts/test-packages.mjs` cover distribution. Catalog hierarchy/adoption lives in `apps/playground/src/catalog/CatalogBreadcrumb.tsx`, used by DocumentationPage and CatalogNotFound; Inspection owns examples. Validate native links/current item/decorative separators, hash/subpath/history/focus, themes, narrow and reset-free rendering with catalog registry/component and router tests plus browser checks.

Native security/error compatibility is API-owned in `apps/api/src/examples/policy-app/`: `configuration.ts` validates explicit Host/Origin/cookie/CSRF settings, `security.ts` owns native scoped hooks and typed request-local authentication, `errors.ts` installs the application-only error contract, and `app.ts` composes a ready non-listening sibling factory. `app.test.ts`, `configuration.test.ts`, `errors.test.ts` and `network.test.ts` cover ordering, failures, isolation, canonical-contract preservation and loopback header/listener behavior. See `docs/SERVER.md#native-application-policy-example`; this is not mounted by either existing startup entry point and adds no shared-library API.

Operational logging and resource cleanup are API-owned in `apps/api/src/examples/operational-app/`: `configuration.ts`, `logging.ts` and `lifecycle.ts` feed the ready non-listening `app.ts`. Colocated configuration/logging/lifecycle/application tests cover explicit bounds, redaction, nonempty safe events, acquisition rollback, cooperative cancellation, ordered cleanup and independent probes. `runner.test.ts` composes the real factory/async runner over loopback, including repeated use, startup signals and native-timeout rollback; `async-app/process.test.ts` exercises built operational composition in real child processes. `network.test.ts` covers real loopback requests/listen failure and listener release. See `docs/SERVER.md#operational-logging-and-resource-example`. Packed native logging compatibility belongs to `scripts/fixtures/server-compatibility/` and `pnpm test:server-compat`; no process or logging policy moves into the shared library.
