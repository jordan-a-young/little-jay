# Task-to-file map

All paths below are relative to the repository root. Start with the matching row and read the applicable `AGENTS.md` files before editing. Tests run through the root configuration; see [root guidance](../AGENTS.md#commands-and-verification) for commands and the [verification matrix](VERIFICATION.md) for check selection and build prerequisites.

This is a navigation aid, not a complete inventory. Check current code before assuming a path or contract is authoritative. Keep this map and affected scoped guidance current in the same change when workspace layout, task ownership, mapped paths, entry points, generators, or test locations change. Add a row for a new task area, update moved paths, and remove obsolete entries. No update is needed for internal edits that leave the map accurate.
